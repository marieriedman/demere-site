# demere-site

Public pages for Demere, served by GitHub Pages at https://marieriedman.github.io/demere-site/.

`privacy/index.html` is a copy of `docs/privacy/index.html` in the private demere repo, which is the
source of truth. Edit it there, then copy it here.

Flipside's pages (`flipside/`, `.well-known/assetlinks.json`) are copies of `site/` in the private flipside repo,
which is their source of truth. `assetlinks.json` is shared: add any other app's App Links statement to the same file.
